# Statistical-hypothesis-testing-Yandex-Knigi-and-AB-test


## 📊 Аналитический проект: Проверка статистических гипотез — активность в Яндекс Книгах и A/B-тест интерфейса интернет-магазина

Это учебный проект Яндекс Практикума

**ЦЕЛЬ ПРОЕКТА**: с помощью статистической проверки гипотез (1) выяснить, проводят ли пользователи из Санкт-Петербурга в приложении «Яндекс Книги» больше времени, чем пользователи из Москвы, и (2) оценить корректность и результаты A/B-теста нового интерфейса интернет-магазина BitMotion Kit.

---
### 📁 СТРУКТУРА
* **Часть 1. Сравнение активности пользователей Яндекс Книг (t-тест)**
* **Часть 2. Анализ результатов A/B-теста интерфейса BitMotion Kit (z-тест для пропорций)**
* **Выводы по каждой части в виде аналитических записок**

---
### 🔍 Содержание анализа
#### Часть 1. Активность пользователей Яндекс Книг: Москва и Санкт-Петербург
* Первичный осмотр данных: типы, пропуски, описательные статистики
* Сравнение групп по размеру, статистикам и распределению (гистограммы, логарифмическая шкала)
* Анализ выбросов по правилу 1,5·IQR
* Проверка дубликатов по идентификатору пользователя
* Односторонний t-тест Уэлча (α = 0,05)
* Аналитическая записка: интерпретация p-value и возможные причины результата

#### Часть 2. A/B-тест нового интерфейса BitMotion Kit
* Проверка корректности проведения теста: равномерность групп, дубликаты, пересечения с конкурирующим тестом
* Расчёт лайфтайма и отбор событий за первые 7 дней после регистрации
* Оценка достаточности выборки (базовая конверсия 30%, мощность 80%, достоверность 95%)
* Расчёт конверсии в покупку по группам
* Односторонний z-тест для двух пропорций (α = 0,05)
* Сравнение фактического эффекта с целевым (+3 п.п.) и выводы

---
### ✔️ Результаты

**Часть 1. Яндекс Книги**
* Нулевая гипотеза **не отвергнута**: p-value = 0,2182 при α = 0,05
* Статистически значимых оснований считать, что пользователи из Санкт-Петербурга активнее москвичей, нет
* Данные сильно скошены вправо: медиана активности менее 1 часа, а среднее — около 11 часов
* В данных найдено 244 повторяющихся идентификатора (пользователи, встречающиеся в обоих городах)

**Часть 2. A/B-тест BitMotion Kit**
* Из анализа исключены 887 пользователей, участвовавших сразу в двух тестах, — осталось 9 963 участника (A — 4 952, B — 5 011)
* Размер выборки достаточен: необходимо 3 762 пользователя в группе
* Конверсия за 7 дней: группа A — 27,81%, группа B — 29,54% (**+1,73 п.п.**)
* z-статистика = 1,907, p-value = 0,0283 — рост конверсии статистически значим
* Целевой эффект (**+3 п.п.**) не достигнут
